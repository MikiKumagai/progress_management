# 学習管理アプリ

学習課題の登録、日々の進捗記録、残量グラフ、完了日予測、単語帳学習をまとめて扱うデスクトップアプリ。  
進捗を可視化することでモチベーションを維持するとともに、今後の学習計画を立てやすくすることを目的に作成。

## 概要

資格試験や語学学習のように、一定量を継続して進める学習を想定
課題ごとに総量と進捗単位を設定し、日々の進捗を記録すると、残りの学習量をグラフで確認可能。
さらに記録済みデータをもとに線形回帰で完了予定日も算出。

単語帳として登録した課題では、単語・意味の登録、学習状態の管理、辞書形式での確認が可能。

## 主な機能

- 累計入力 / 差分入力による進捗記録
- 学習課題の新規登録
- 課題ごとの進捗率表示 / 残量推移のグラフ表示 / 線形回帰による完了予定日の予測
- 単語帳の作成・編集
- 2パターンの単語帳学習：単語を見て意味を答える / 意味を見て単語を答える

## 使用技術

- Python
- Tkinter
- SQLite
- pandas
- Matplotlib
- scikit-learn

## ディレクトリ構成

```text
.
├── db/              # テーブル定義、初期データ、CSV入出力
├── models/          # SQLiteへのアクセス処理
├── presentations/   # グラフ・表表示用データの整形
├── services/        # 進捗計算、予測、課題・単語帳の操作
└── ui/              # Tkinterによる画面実装
```

## セットアップ

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m ui.app
```

## データをCSVに出力

```bash
python3 -m db.export_csv
```
