# 学習管理アプリ

学習課題の登録、日々の進捗記録、残量グラフ、完了日予測、単語帳学習をまとめて扱うデスクトップアプリです。  
進捗を可視化することで、モチベーションを維持するとともに、今後の学習計画を立てやすくします。

## 概要

資格試験や語学学習のように、一定量を継続して進める学習を想定しています。  
課題ごとに総量と進捗単位を設定し、日々の進捗を記録すると、残りの学習量をグラフで確認できます。記録済みデータをもとに線形回帰で完了予定日も算出します。

単語帳として登録した課題では、単語・意味の登録、学習状態の管理、辞書形式での確認ができます。

## 主な機能

- 学習課題の登録
- 累計入力・差分入力による進捗記録
- 課題ごとの進捗率表示
- 残り学習量のグラフ表示
- 学習履歴に基づく完了予定日の予測
- 単語帳の作成・編集
- 単語と意味それぞれの学習状態管理
- CSVからの初期データ投入

## 使用技術

- Python
- Tkinter
- SQLite
- pandas
- Matplotlib
- scikit-learn

Tkinter、SQLite、csv、datetimeなどはPython標準ライブラリを使用しています。  
外部パッケージとして明示的に必要なのは、主にデータ加工・グラフ描画・完了日予測に使っているライブラリです。

## ディレクトリ構成

```text
.
├── db/              # テーブル定義、初期データ、CSV入出力
├── models/          # SQLiteへのアクセス処理
├── presentations/   # グラフ・表表示用データの整形
├── services/        # 進捗計算、予測、課題・単語帳の操作
└── ui/              # Tkinterによる画面実装
```

## セットアップ

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python db/init_db.py
python -m ui.app
```

`db/init_db.py` を実行すると、CSVファイルをもとに `db/progress.db` が作成されます。

## 工夫した点

- 進捗入力を「累計」と「差分」の両方に対応させ、学習スタイルに合わせて記録できるようにしました。
- 進捗記録、課題情報、単語帳データをSQLiteで管理し、画面側とデータ操作を分離しました。
- pandasで日付別の進捗データを整形し、Matplotlibで残量推移を可視化しています。
- 過去の進捗からscikit-learnの線形回帰を使って完了予定日を予測しています。
- 単語帳では「単語を見て意味を答える」「意味を見て単語を答える」学習を分けて扱えるようにしました。
